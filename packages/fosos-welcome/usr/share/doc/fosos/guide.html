FosOS

FosOS is a Debian desktop. Firefox is the only preinstalled browser. Optional software is installed with APT.

Install

From the live session, choose Install FosOS. The installer asks for a language, keyboard, disk, and account. The disk can be encrypted. The live password is live if the installer asks for permission.

After it finishes, restart and boot the disk. Detach the installation image, or the machine will start the live session again.

First login

Welcome shows whether the network is connected and can install updates. Finish setup hides that window. Open Welcome to FosOS from the menu if you want it back.

Packages

FosOS components update from the FosOS archive. Debian updates stay on the Debian archive. Firefox is still the only browser. This guide is package version 0.1.1.

fos update refreshes package lists. fos upgrade installs available upgrades. fos install and fos remove add and remove packages. If an install stops halfway, fos repair finishes or undoes it. Use APT itself for anything else.

Recovery

On the live image, Ctrl+Alt+F2 opens a console. Sign in as user with password live. Ctrl+Alt+F1 returns to the desktop. An installed system uses the account created during installation.

Reinstall

Boot the live image again, choose Install FosOS, and erase the disk. That replaces the previous installation.
